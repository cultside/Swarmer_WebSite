# SWARMER

Сайт боксерского клуба одного тренера — Федорова Максима.

Одностраничный статический сайт: чистые HTML, CSS и JavaScript, без зависимостей и сборки.

## Структура

```
swarmer-site/
├── index.html      — разметка всех секций
├── styles.css      — оформление и адаптив
├── script.js       — аккордеон в разделе вопросов
├── assets/
│   ├── wraps.jpg   — перемотка бинтов, фон первого экрана
│   ├── press.jpg   — боксёр в толпе репортёров, раздел «О клубе»
│   ├── action.jpg  — бой в ринге, раздел «Спарринг»
│   └── boxer.jpg   — боксёр на крыше, раздел «Тренер»
└── .gitignore
```

## Запуск локально

Просто откройте `index.html` в браузере — этого достаточно, так как зависимостей нет.

Если нужен полноценный локальный сервер (например, чтобы проверить пути к изображениям):

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите в него содержимое этой папки.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите источник **Deploy from a branch**, ветку **main** (или **master**) и папку **/ (root)**.
5. Нажмите **Save**. Через минуту-две сайт будет доступен по адресу
   `https://<имя-пользователя>.github.io/<имя-репозитория>/`.

### Команды для терминала

git branch -M main

Если `git` сообщает о том, что не настроено имя пользователя:

```bash

git config --global user.email "ваша@почта.ru"
```

## Запуск на собственном сервере

Сайт статический, поэтому подойдёт любой веб-сервер. Проверить, что всё работает:

```bash
# Проверить наличие файлов
curl -I https://<ваш-домен>/

# Nginx: положить файлы в корень сайта
/usr/share/nginx/html/

# или Python на сервере
python3 -m http.server 8000
```

Для продакшена удобнее всего Nginx или Caddy с автопродлением сертификата.

## Что можно менять

| Что | Где |
|---|---|
| Тексты вопросов и ответов | `index.html`, блок `<section id="faq">` |
| Телефон | `index.html`: текст `.phone` и `href` у `tel:` ссылки |
| Ссылка на Telegram | `index.html`, кнопка «Написать в Telegram» |
| Фотографии | заменить файлы в `assets/`, имена сохранить |
| Яркость фона в шапке | `styles.css`, `.masthead-bg` → `filter` |
| Цвета | `styles.css`, переменные в `:root` |

Фотографии в `assets/` подобраны под пропорции рамок: `wraps.jpg` — фон (широкий кадр), `press.jpg` — горизонтальная рамка 16:9, `action.jpg` — квадрат 1:1, `boxer.jpg` — вертикаль 4:5. Если замените фото на другие пропорции, поправьте `aspect-ratio` у соответствующих классов `.shot--*`.

## Адаптив

Сайт рассчитан на три диапазона:

- **десктоп** (больше 900px) — двухколоночные секции с фотографиями;
- **планшет** (до 900px) — колонки складываются в одну;
- **смартфон** (до 640px) — вертикальный формат, все фото в соотношении 4:5, кнопки во всю ширину, шапка на высоту экрана с учётом адресной строки (`100svh`).
